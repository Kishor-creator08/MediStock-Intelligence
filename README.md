# MediStock Intelligence – Healthcare Inventory Analytics

## Project Overview
MediStock Intelligence is a healthcare inventory analytics project designed to analyze medicine stock levels, identify shortages, monitor expiry risks, and support better inventory management across multiple hospitals.

## Business Problem
Hospitals need to maintain sufficient medicine inventory while avoiding stock shortages, excess stock, and medicine expiry. This project uses SQL and Python to convert inventory data into actionable insights.

## Technologies Used
- MySQL
- Python
- Pandas
- Matplotlib
- MySQL Connector

## Database Design
The project contains four relational tables:
- Hospitals
- Medicines
- Suppliers
- Inventory

## Key Analysis
1. Hospital-wise inventory analysis
2. Medicine stock distribution
3. Low-stock identification
4. Stock shortage analysis
5. Inventory valuation
6. Medicine expiry monitoring
7. Supplier performance analysis
8. Hospital stock comparison
9. Reorder recommendations
10. Inter-hospital stock transfer opportunities

## Visualizations
Three visualizations are generated using Python:
- Hospital Inventory Value
- Low Stock and Shortage Analysis
- Medicine Stock Distribution

## Key Features
- SQL-based healthcare inventory analysis
- Python and MySQL integration
- Automated analysis reports
- Inventory visualization
- Expiry-aware stock transfer recommendations

## Dataset
This project uses sample/synthetic hospital inventory data for demonstration and analytical purposes. It does not represent actual hospital records.

## Project Outcome
The project demonstrates how SQL and Python can be used to analyze healthcare inventory data, identify potential stock management issues, and support data-driven decisions.
